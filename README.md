# Apify Dashboard

A full-stack apify dashboard application with separate front-end and back-end directories.

## 📁 Project Structure

```
apify-dashboard/
├── front-end/   # Front-end code
└── back-end/    # Back-end code
```

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/RevanthB007/apify-dashboard.git
cd apify-dashboard
```

Or if downloading ZIP:  
Extract the contents and open the folder.

### 2. Install Dependencies

Install dependencies for both front-end and back-end using two separate terminals.

#### Terminal 1 — Backend

```bash
cd back-end
npm install
```

#### Terminal 2 — Frontend

```bash
cd front-end
npm install
```

### 3. Run the App

Start both the front-end and back-end in parallel using the two terminals:

#### Terminal 1 — Start Backend

```bash
cd back-end
npm run dev
```

#### Terminal 2 — Start Frontend

```bash
cd front-end
npm run dev
```

Your application should now be running locally with both services active.
